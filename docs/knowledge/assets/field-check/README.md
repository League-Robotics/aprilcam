# field-check

`field_check.py` is an out-of-process sanity check for a playfield. It detects every ArUco/AprilTag in one raw camera frame, compares the layout with a playfield definition, fits a pixel-to-world homography over the surveyed markers, and writes an annotated image. It reports ids seen, missing, stray and duplicated, marker side in pixels, marker orientation, per-marker residual and leave-one-out residual in cm. It was written on 2026-10-16 to find that main-playfield ids 9 and 10 were physically swapped (30 cm rms swapped, 0.23 cm rms once right). It never talks to the daemon. Usage: `uv run python docs/knowledge/assets/field-check/field_check.py FRAME.png config/aprilcam/playfields/main-playfield.json OUT.png --calibration ~/.local/share/aprilcam/cameras/<slug>/calibration.json`, with the frame captured by `aprilcam camera image 2 --encoding png -o FRAME.png`. Runbook: `docs/knowledge/2026-10-16-pose-field-calibration-live-acceptance-runbook.md`.
